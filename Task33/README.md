To-Do List REST API
Project Overview
This project is a To-Do List REST API built using Node.js and Express.js. It allows users to create, retrieve, update, and delete tasks using HTTP requests.
The API follows REST principles and supports all four CRUD operations.

Technologies Used
Node.js
Express.js
JavaScript
Postman
REST API
JSON

Features
Create a new task.
Retrieve all tasks.
Retrieve a task by its ID.
Update an existing task.
Update task completion status.
Delete a task.
