# Online Shoe Store 👟

## Description
A React-based online shoe store where users can browse shoes, add products to their shopping cart, manage quantities, and calculate the total price.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Features
- Display available shoes.
- Add shoes to cart.
- Increase or decrease quantity.
- Remove items from cart.
- Calculate total price automatically.

## Installation

```bash
npm install
npm run dev
```

## React Concepts
- useState Hook
- Event Handling
- Array Methods (map, filter, reduce)
