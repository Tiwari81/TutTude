# Greenwood Public Library

A responsive library website built using HTML, Tailwind CSS, and JavaScript. It provides information about library sections, facilities, membership plans, upcoming events, and contact details.

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript
- Google Fonts

## Features
- Responsive navigation bar
- Hero section
- Library sections
- Image gallery with zoom functionality
- Membership plans
- Testimonials
- Contact section
- Upcoming events
- Responsive footer
- Mobile navigation menu

## Project Structure

```text
greenwood-library/
│
├── index.html
├── script.js
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Make sure you have an internet connection for Tailwind CSS, Google Fonts, and external images.
